# FREELA — Рабочее пространство для фрилансеров и креаторов

Современное веб-приложение на **React 19 + TypeScript + Vite + Tailwind CSS**.
Полный исходный код с готовой архитектурой управления проектами, клиентами, задачами, финансовым потоком и циклом создания контента («Идея → Контент → Результат»).

---

## 🚀 Быстрый старт локально

### Требования
- **Node.js** версии 18 или новее (рекомендуется LTS 20+)
- **npm**, **yarn** или **pnpm**

### 1. Установка зависимостей
Откройте папку проекта в терминале (или в терминале Visual Studio Code) и выполните:

```bash
npm install
```

### 2. Запуск локального сервера разработки
```bash
npm run dev
```

После запуска откройте в браузере адрес:
```
http://localhost:3000
```
*(или другой порт, указанный в терминале)*

### 3. Сборка для продакшена (Production Build)
```bash
npm run build
```
Готовые статические файлы будут скомпилированы в директорию `dist/`.

Для проверки продакшен-сборки локально:
```bash
npm run preview
```

## 🛠 Работа в Visual Studio Code

1. Распакуйте ZIP-архив в удобную папку.
2. Запустите VS Code и выберите **File → Open Folder...** (Файл → Открыть папку) и выберите эту папку.
3. Откройте встроенный терминал в VS Code (<kbd>Ctrl</kbd> + <kbd>`</kbd> или <kbd>Cmd</kbd> + <kbd>`</kbd> на macOS).
4. Выполните `npm install`, затем `npm run dev`.
5. Рекомендуемые плагины для VS Code:
   - **Tailwind CSS IntelliSense**
   - **TypeScript Vue/React Plugin**
   - **ESLint**
   - **Prettier**

## 🌐 Развёртывание (Deployment)

### Загрузка на GitHub

1. Инициализируйте Git-репозиторий в папке проекта:
   ```bash
   git init
   git add .
   git commit -m "Initial commit of FREELA"
   ```
2. Создайте новый репозиторий на [GitHub](https://github.com/new).
3. Привяжите репозиторий и отправьте код:
   ```bash
   git branch -M main
   git remote add origin https://github.com/ВАШ_ЛОГИН/ВАШ_РЕПОЗИТОРИЙ.git
   git push -u origin main
   ```

---

### Развёртывание на Vercel

1. Зайдите на [vercel.com](https://vercel.com) и авторизуйтесь через GitHub.
2. Нажмите **«Add New...» → «Project»**.
3. Выберите ваш репозиторий с FREELA и нажмите **«Import»**.
4. Vercel автоматически определит **Vite**:
   - **Framework Preset**: `Vite`
   - **Build Command**: `npm run build`
   - **Output Directory**: `dist`
   - **Install Command**: `npm install`
5. Нажмите кнопку **«Deploy»**. Через 30 секунд проект будет опубликован и получит бесплатный HTTPS-домен `*.vercel.app`.

В проекте уже создан файл `vercel.json`, обеспечивающий корректный роутинг.

## ⚡ Особенности FREELA

- **Offline-First & LocalStorage**: все ваши проекты, задачи, клиенты и контент сохраняются в локальном хранилище браузера и не пропадают при перезагрузке.
- **Интеллектуальный блок «Следующий шаг»**: автоматически рассчитывает фокус дня на основе приближающихся дедлайнов, зависших оплат и готового к публикации контента.
- **Эффективная ставка**: автоматический расчет стоимости часа работы по проектам.
- **Генератор кейсов**: создание готового описания проекта в формате Markdown в 1 клик для вашего портфолио.
- **Глобальный поиск <kbd>⌘K</kbd>**: мгновенная навигация по всем сущностям приложения.
- **Экспорт и импорт**: возможность сделать полную резервную копию базы данных в JSON.
